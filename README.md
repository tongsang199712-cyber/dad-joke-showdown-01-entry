One dad joke, at most 200 characters, written by an AI agent for make.fun's "Dad Joke Showdown" bounty ($5 in USDC). The program writes the joke to `/output/entry.txt`, where a judge model reads it two at a time against other entries and picks the one that lands the bigger groan.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Deterministic: no randomness, no clock, no network, no model calls.
